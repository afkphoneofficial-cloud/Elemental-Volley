============================================================
ล็อกอิน กับ Supabase
============================================================
ต้องคู่กันถ้าจะเก็บลูกค้าจริง

ล็อกอินอย่างเดียว (Google GIS ในหน้าเว็บ) = ได้ Gmail แต่เซฟยังอยู่เครื่องผู้เล่น
Supabase = บัญชี + โปรไฟล์ + เซฟขึ้นคลาวด์ + กันชื่อซ้ำ

โค้ดเกมบังคับหน้า auth แล้ว
supabaseUrl / supabaseAnonKey ยังต้องวางเองใน js/config/backend.js
อย่าเปิดล็อกอินบนโดเมนจริงก่อนใส่ Authorized JavaScript origins
ยังไม่ใช้ Stripe จนกว่าร้านรับเงินจริง

ขั้นตอนเมื่อจะเปิดล็อกอิน (ทำครั้งเดียว) ดูไฟล์ supabase/สิ่งที่ต้องเซ็ต.txt
สรุป:
- Google Cloud → Authorized JavaScript origins ใส่
    https://evolley.dev
    https://www.evolley.dev
    https://elemental-volley.vercel.app
    http://localhost:5500
    http://127.0.0.1:5500
- สร้างโปรเจกต์ Supabase → เปิด Google provider → รัน schema.sql
- วาง URL + anon key ใน js/config/backend.js
- ค่อยสลับ BootScene จาก menu เป็น auth

อย่าเปิดล็อกอินบนก่อนใส่ origins ปุ่ม Google จะพังบนโดเมนจริง
ยังไม่ใช้ Stripe จนกว่าร้านรับเงินจริง


============================================================
1) ออนไลน์ · ปิง · pause / reconnect
============================================================
สถานะ: บรีฟแล้ว  ยังไม่โค้ด

คอสตูม / เอฟเฟกต์ตบพิเศษ
- เป็นความสวยและความตื่นเต้นเท่านั้น ไม่กระทบ MVP
- ทำฝั่งไคลเอนต์ (ภาพ+เสียง) ห้ามใส่ในฟิสิกส์ ห้ามซิงก์อนุภาคผ่านเน็ต
- เครื่องทั้งสองเห็นเอฟเฟกต์จากอินพุตชุดเดียวกัน หรือสุ่มด้วยซีดร่วม ถ้าต้องตรงกัน

ปิงกับการ pause คนละเรื่อง
- เกมล็อกฟิสิกส์ 25 เฟรม ปิงไม่แก้ด้วยการพักเกม
- ออนไลน์ส่งแค่ปุ่มกด ไม่ส่งตำแหน่งลูก
- ทั้งสองเครื่องรันซิมชุดเดียวกัน (ล็อกสเต็ป)
- ปิงสูงใช้ rollback สั้นๆ แบบเกมไฟต์ติ้ง ไม่ดีเลย์ทั้งแมตช์
- ปิงสูงแต่ยังต่ออยู่ = เล่นต่อด้วยเน็ตโค้ด ไม่ pause

pause จากผู้เล่น (มารยาท ไม่ใช่แก้แล็ก)
- คนละ 1 ครั้งต่อแมตช์
- สูงสุด 20–30 วินาที โชว์นาฬิกาให้อีกฝั่งเห็น
- ห้ามกดตอนลูกกำลังจะตกพื้น / จังหวะได้แต้ม (กันโกงจังหวะ)
- หมดเวลาแล้วยืนเกมต่อเอง

pause จากระบบ (หลุดเน็ตเท่านั้น)
- ไม่พักอัตโนมัติเพราะปิงสูงหรือแพ็กเกจหล่นเป็นพักสั้นๆ
- พักเมื่อขาดการเชื่อมต่อจริง รอ reconnect 20–30 วิ
- ไม่กลับมา = อีกฝั่งชนะ (disconnect forfeit)
- หน้าต่างนี้แยกจาก pause ผู้เล่น

กรอบเวลาที่รับได้
- ไม่ใช้ 1 นาทีต่อครั้ง (ยาวเกินแมตช์ถึง 15)
- worst case ประมาณ ผู้เล่นคนละครั้ง 20–30 วิ + ระบบรอ reconnect 20–30 วิ แล้วจบแมตช์

ตอนทำจริงให้ทวน
- [ ] เน็ตโค้ด: อินพุต + ล็อกสเต็ป + rollback
- [ ] pause ผู้เล่น คนละ 1 ครั้ง 20–30 วิ + นาฬิกา + กันกดจังหวะแต้ม
- [ ] reconnect 20–30 วิ แล้ว forfeit
- [ ] คอสตูม/FX พิเศษ ไม่เข้าซิม

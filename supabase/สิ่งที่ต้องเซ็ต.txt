------------------------------------------------------------
7) เซิร์ฟแมตช์บน VPS ไทย (ทำหลังเช่าเครื่อง Linux)
------------------------------------------------------------
เกมเว็บยังอยู่ Vercel   สมาชิกยังอยู่ Supabase
เครื่อง VPS ทำแค่ WebSocket แมตช์สด ที่ wss://play.evolley.dev

ค่าที่เกมชี้ไปแล้ว
  js/config/backend.js → matchWsUrl: "wss://play.evolley.dev"

ขั้นตอนบนเครื่อง (SSH เข้า VPS เป็น Linux ไม่ใช้ Windows)

1. ชี้โดเมน
   ที่ผู้ขายโดเมน สร้างเรคคอร์ด A
     play.evolley.dev  →  ไอพีของ VPS
   รอ DNS ขึ้น (ลอง ping play.evolley.dev)

2. เปิดพอร์ตไฟร์วอลล์
   22 (SSH)  80  443
   อย่าเปิดพอร์ต Postgres ออกเน็ต

3. ติดตั้งพื้นฐาน
   sudo apt update
   sudo apt install -y git curl nginx
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt install -y nodejs
   sudo npm i -g pm2

4. ดึงโค้ดเกม (หรือ scp เฉพาะโฟลเดอร์ server/match ก็ได้)
   cd /opt
   sudo git clone https://github.com/afkphoneofficial-cloud/Elemental-Volley.git evolley
   cd /opt/evolley/server/match
   sudo npm install

5. สร้างไฟล์สภาพแวดล้อม
   sudo nano /opt/evolley/server/match/.env
   ใส่ให้ครบ (anon key คัดจาก js/config/backend.js ค่า supabaseAnonKey)

     PORT=8787
     MAX_LIVE_MATCHES=12
     DECLINE_COOLDOWN_MS=300000
     OFFER_MS=15000
     SUPABASE_URL=https://njuhuhfehbrbmatfpxcf.supabase.co
     SUPABASE_ANON_KEY=วาง anon public ตรงนี้
     ALLOWED_ORIGINS=https://evolley.dev,https://www.evolley.dev,https://elemental-volley.vercel.app

   MAX_LIVE_MATCHES=12  คือสูงสุด 12 แมตช์พร้อมกันบน VPS+1
   คนเกินโควต้ายังเห็นแค่หน้าค้นหาคู่  ไม่บอกว่าเซิร์ฟเต็ม

6. รันด้วย pm2 ให้ตื่นเองหลังรีบูต
   cd /opt/evolley/server/match
   sudo pm2 start index.mjs --name evolley-match --update-env
   sudo pm2 save
   sudo pm2 startup
   (copy คำสั่งที่มันพิมพ์แล้วรันตาม)

   ตรวจ
     curl http://127.0.0.1:8787
     ต้องขึ้น evolley-match ok

7. ใบรับรอง HTTPS + บังคับ WSS
   sudo apt install -y certbot python3-certbot-nginx
   สร้างไฟล์ /etc/nginx/sites-available/play.evolley.dev

     server {
       listen 80;
       server_name play.evolley.dev;
       location / {
         proxy_pass http://127.0.0.1:8787;
         proxy_http_version 1.1;
         proxy_set_header Upgrade $http_upgrade;
         proxy_set_header Connection "upgrade";
         proxy_set_header Host $host;
         proxy_read_timeout 86400;
       }
     }

   sudo ln -s /etc/nginx/sites-available/play.evolley.dev /etc/nginx/sites-enabled/
   sudo nginx -t && sudo systemctl reload nginx
   sudo certbot --nginx -d play.evolley.dev

8. ตรวจจากเครื่องคุณ
   เปิด https://evolley.dev ล็อกอิน Gmail สองไอดี
   Rank Mode ทั้งคู่เข้าคิว ต้องขึ้นปุ่มยอมรับ/ปฏิเสธกลางจอ
   ปฏิเสธแล้วฝ่ายนั้นพักค้น 5 นาที ฝ่ายถูกปฏิเสธค้นต่อเอง
   Exhibition กดจากรายชื่อเพื่อน อีกฝ่ายต้องออนไลน์อยู่ที่ล็อบบี้

  cd /opt/evolley && sudo git pull && cd server/match && sudo npm i && sudo pm2 restart evolley-match

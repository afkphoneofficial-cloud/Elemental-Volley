สิ่งที่ต้องไปเปิด (ทำครั้งเดียว)

1) Google Cloud Console
   - OAuth client ที่ให้มาใช้ได้ (นี่คือ Client ID ไม่ใช่รหัสลับ)
   - Authorized JavaScript origins ใส่ URL ที่เปิดเกมจริง เช่น
       http://localhost:5500
       http://127.0.0.1:5500
       https://โดเมนจริงของคุณ
   - อย่าเปิดเกมด้วยไฟล์ file:// Google จะไม่ยอม
   - คัดลอก Client Secret ไปใส่ใน Supabase เท่านั้น ห้ามใส่ในเกม

2) Supabase (แนะนำ — เป็นฐานข้อมูลลูกค้า + login)
   - สร้างโปรเจกต์
   - Authentication → Providers → Google
       Client IDs = 441173887104-aked2gdmq0co0fou4hlq3vsj0ra4q6ms.apps.googleusercontent.com
       Client Secret = จาก Google Cloud
   - SQL Editor รันไฟล์ supabase/schema.sql
   - Settings → API คัดลอก Project URL กับ anon public key
   - วางลง js/config/backend.js ที่ supabaseUrl และ supabaseAnonKey

3) Vercel (ตอนจะขึ้นเน็ต)
   - Deploy โฟลเดอร์เกม
   - เอาโดเมน Vercel ไปเพิ่มใน Google origins และ Supabase redirect URLs
       https://<โปรเจกต์>.supabase.co/auth/v1/callback

ยังไม่ต้องใช้ Stripe จนกว่าร้านค้าจะรับเงินจริง

------------------------------------------------------------

  441173887104-aked2gdmq0co0fou4hlq3vsj0ra4q6ms.apps.googleusercontent.com

Authorized JavaScript origins ใส่โดเมนด้านบนทั้งหมด

Authorized redirect URIs ไม่ต้องใส่ GIS popup ก็ได้
แต่ถ้า Supabase ขอ ให้ใส่
  https://<รหัสโปรเจกต์>.supabase.co/auth/v1/callback

คัดลอก Client Secret ไปใส่ใน Supabase เท่านั้น
ห้ามวางในเกม ห้าม commit


------------------------------------------------------------
2) Supabase  →  New project
------------------------------------------------------------
Authentication → Providers → Google
  Client IDs = Client ID ด้านบน
  Client Secret = จาก Google Cloud
  เปิด Enable

Authentication → URL Configuration
  Site URL = https://evolley.dev
  Redirect URLs ใส่ทุกโดเมนในลิสต์บน และ
  https://<รหัสโปรเจกต์>.supabase.co/auth/v1/callback

SQL Editor  →  วางทั้งไฟล์ supabase/schema.sql  →  Run

Settings → API
  Project URL          →  คัดลอก
  anon public          →  คัดลอก
  service_role         →  ห้ามใส่ในเกม

วางสองค่าลง js/config/backend.js
  supabaseUrl: "https://xxxx.supabase.co"
  supabaseAnonKey: "eyJ..."

จากนั้น git commit / push แล้วกด Create Deployment ที่ Vercel
หรือทดสอบ local แล้วรีเฟรชหน้าเกม


------------------------------------------------------------
3) ตรวจว่าติด
------------------------------------------------------------
เปิดเกม ต้องเจอหน้าเข้าสู่ระบบ ไม่ข้ามไปเมนู
กด Google ด้วย Gmail ตั้งชื่อ 2–16 ตัว แล้วเข้าล็อบบี้
Dashboard → Authentication → Users ต้องมีอีเมล
Table Editor → profiles ต้องมีแถว + save_data หลังเลือกตัวละครแรก


------------------------------------------------------------
4) สุ่มเพื่อนจากเซิร์ฟ (ทำครั้งเดียว ถ้าเคยรัน schema ไปแล้ว)
------------------------------------------------------------
SQL Editor → วางทั้งไฟล์ supabase/friends_directory.sql → Run
จากนั้นรีเฟรชเกม แล้วกด สุ่มจากเซิร์ฟ ต้องขึ้นการ์ด 3–5 คน


------------------------------------------------------------
5) กล่องจดหมาย + คำเชิญเพื่อน (ทำครั้งเดียว)
------------------------------------------------------------
SQL Editor → วางทั้งไฟล์ supabase/mailbox.sql → Run
จากนั้นรีเฟรชเกม ส่งคำเชิญจากไอดีหนึ่ง ไอดีหนึ่งต้องมีจดหมายมุมขวาล็อบบี้

ข่าวสารจากเซิร์ฟ/ทีมพัฒนาในอนาคต: insert แถวในตาราง mail
  kind = news | server | dev
  ใส่ title_th title_en body_th body_en และ user_id ของผู้รับ


------------------------------------------------------------
6) แชทโลก + แชทเพื่อน (ทำครั้งเดียว)
------------------------------------------------------------
SQL Editor → วางทั้งไฟล์ supabase/chat.sql → Run
จากนั้นรีเฟรชเกม จะมีแทบแชทมุมซ้ายล่างของล็อบบี้ พับเปิด-ปิดได้
แชทโลกเก็บสูงสุด 30 ข้อความและเคลียร์ทุก 10 นาที  แชทเพื่อนเก็บ 30 บรรทัดล่าสุด

ถ้าเคยรัน chat.sql ไปแล้ว ให้ Run ไฟล์นี้อีกครั้งเพื่ออัปเดตเพดานข้อความ

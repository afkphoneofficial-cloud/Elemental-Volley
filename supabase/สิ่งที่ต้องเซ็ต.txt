9) สำรองเซฟอัตโนมัติ (ทำครั้งเดียว + เปิดแบ็กอัปโปรเจกต์)
------------------------------------------------------------
ผู้เล่นไม่ต้องกดส่งออก  เกมเขียน save_data ตามเดิม
SQL Editor → วางทั้งไฟล์ supabase/save_snapshots.sql → Run

จากนั้นทุกไอดีจะมีประวัติในตาราง save_snapshots
  หลังแข่ง Rank จะเก็บทันที (สถานะก่อนเขียนทับ)
  การเซฟอื่น (สกิน / เลเวล) เก็บได้ไม่เกิน 1 ครั้งต่อ 6 ชั่วโมง
  เก็บล่าสุด 14 ชุดต่อไอดี ชุดเก่าถูกทิ้งเอง
  ไอดีที่มีเซฟอยู่แล้วจะได้แถว seed ตอนรันไฟล์

กู้ไอดีที่พัง (ทำเองใน Dashboard ไม่โชว์ในเกม)
  Table Editor → save_snapshots กรอง user_id = รหัสไอดี
  ดู created_at / reason แล้วคัด id ของแถวที่ต้องการ
  SQL Editor:

select public.admin_restore_save(
  'วางรหัสไอดี'::uuid,
  'วางรหัสแถวสำรอง'::uuid
);

ผู้เล่นต้องรีเฟรชเกมหรือล็อกอินใหม่ถึงจะได้เซฟที่กู้
อย่าให้ anon / authenticated เรียกฟังก์ชันนี้

แบ็กอัปทั้งโปรเจกต์ (คนละชั้นกับตารางด้านบน)
  Dashboard → Project Settings → Database → Backups
  เปิด Daily backups ถ้าแผนรองรับ (Pro มี PITR)
  แผนฟรีมักไม่มีประวัติย้อนวัน  ตาราง save_snapshots จึงเป็นตาข่ายหลัก
  ก่อนรัน SQL ใหญ่ ควร Export ตาราง profiles ด้วย
